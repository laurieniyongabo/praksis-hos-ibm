Oppgavebeskrivelse

Oppgaven går ut på å bygge og sette i drift en fullverdig data-pipeline som demonstrator — fra åpne datakilder på internett til en visualisert sluttapplikasjon, med en data-sentrisk sikkerhetsmodell gjennom hele kjeden.

Kjerneprinsippet er at sikkerheten ikke sitter i nettverket eller applikasjonen, men i dataene selv. Tilgangspolicyer og kryptering knyttes til hvert enkelt datasett og følger det uansett hvilken applikasjon eller bruker som aksesserer det.

Fire faser

  • Plattformoppsett — sette opp dataplattformen på Red Hat OpenShift (ROKS) på IBM Cloud
  • CI/CD — automatisert bygging, testing og deployment av plattformkomponentene
  • Dataintegrasjon og sikkerhet — åpne flydata gjennom pipeline, med attributtbasert tilgangskontroll og kryptering på datalaget
  • Demonstrator — REST API og visualisering som viser hele datareisen fra rådata til brukergrensesnitt

Teknologier

IBM Cloud, Red Hat OpenShift, Kubernetes, GitHub Actions, Apache Kafka, Apache Iceberg, Apache Spark, Trino, watsonx.data, IBM Key Protect, Apache Superset, React og FastAPI.
